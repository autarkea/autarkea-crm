# АЎТАРКЕЯ — CRM, которая не даёт терять счета и заказы

**Твой бизнес живёт в Telegram? Значит, и CRM ему нужна такая.**

Коробочная CRM для бизнеса, который работает заказами и проектами (1–15 человек):
производство на заказ, услуги, аренда, инжиниринг.
Всё в одном месте: задачи, клиенты, проекты, счета и акты. На вашем собственном сервере.
Без ежемесячных платежей за каждого менеджера. Без данных «в облаке где-то там».

## Установить самому

Нужен сервер на Ubuntu 24.04 LTS и доступ к терминалу. Установщик сам проверит зависимости (при необходимости поставит Docker) и дальше проведёт по шагам:

```bash
git clone https://github.com/autarkea/autarkea-crm.git printed4u-crm
cd printed4u-crm && bash install.sh
```

Дальше просто следуйте инструкциям интерактивного установщика:

1. он поднимет контейнеры (NocoDB + бот + вебхук);
2. попросит один раз зарегистрироваться в NocoDB в браузере (`http://IP_сервера:8081`) и вставить API-токен;
3. предложит настроить Telegram-бота, email-отправку, сетевые папки и бэкапы — отвечайте `y`/`n`;
4. в конце покажет адреса для входа и полезные команды.

> 📌 Папка должна называться именно `printed4u-crm` — установочные скрипты ждут этот путь.
>
> 💡 Если установщик только что поставил Docker — перезайдите в систему и запустите `bash install.sh` ещё раз: он продолжит с того же места.

Обновление:

```bash
bash upgrade.sh --dry-run   # посмотреть план, ничего не менять
bash upgrade.sh             # бэкап → миграции → обновление
```

`upgrade.sh` безопасен для данных: перед изменениями делает бэкап базы, миграции аддитивные и идемпотентные — повторный запуск ничего не сломает.

Справились сами? Круто. Если на полпути стало страшно — это нормально, я рядом.

## Про ограничения — честно

- Расчёт на команду до 15 человек (комфортно — 2–8)
- Нужен сервер: подойдёт старый ноутбук или компактный мини-ПК
- Удалённый доступ из дома — через защищённую сеть (Tailscale), настраивается без белого IP

## FAQ

**Чем это лучше amoCRM / Bitrix24 / облачных CRM?**
У них — платишь каждый месяц за каждого менеджера, и данные лежат «где-то в облаке». У нас — заплатил один раз, и система твоя навсегда. Данные — на твоём сервере. Для юрлиц это ещё и вопрос закона о персональных данных.

**Я не умею в серверы. Это мне подойдёт?**
Подойдёт — если я его поставлю. Это моя работа, и делаю я её хорошо. Вам останется просто работать в Telegram.

**Это безопасно?**
Всё работает на вашем сервере. Доступ — только у ваших сотрудников. Код открыт — можно изучить, что и как устроено.

**Что если что-то сломается?**
Сначала система сама пришлёт алерт — да, она умеет следить за собой. Дальше — гарантия от автора и сопровождение. Я не исчезаю после продажи.
