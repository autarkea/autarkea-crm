# 📸 Скриншоты для публичной витрины (README.public.md)

Эта папка — источник картинок для открытого репозитория `autarkea/autarkea-crm`.
`publish.sh` собирает снапшот через `git archive`, поэтому всё, что закоммичено
сюда, автоматически уходит в публичный README.

## Правила съёмки

- **Никаких реальных персональных данных**: клиентов, юрлиц, телефонов, сумм,
  имён сотрудников. Снимать с демо-данных (`seed-demo.sh`) или обезличивать.
- **Никаких секретов**: IP-адреса, порты (`:8081`), токены, ключи, содержимое
  `.env`, служебные подписи контейнеров.
- Формат: PNG или JPG.
- Ширина кадра: 900–1200 px (GitHub жмёт файлы > 1 MB).
- Вес файла: до ~400 KB (суммарно папка должна оставаться лёгкой).
- Один смысловой кадр на файл, без обрезки кнопок и текста.
- Окно/вкладка без лишнего: адресная строка браузера, чужие вкладки, панель задач.

## Проверка перед коммитом

1. Открыть каждый файл глазами — нет ли реальных данных/секретов.
2. `ls -lh` — вес и размеры в норме.
3. Файлы закоммичены в приватный репо — только после этого они попадут в
   публикацию через `./publish.sh`.
